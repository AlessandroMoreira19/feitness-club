SOBRE

Este projeto foi criado com base nos conhecimentos da disciplina de Full Stack...

Tivemos como inspiração inicial o app Fiti, onde o usuário agenda suas aulas...

A partir disso, criamos o site Feitness Club com estrutura dividida em páginas:

HOME

A aba HOME traz uma explicação detalhada do sistema de agendamento e os benefícios oferecidos.

O objetivo é apresentar uma visão clara sobre as funcionalidades disponíveis.

AGENDAMENTOS

A aba AGENDAMENTOS explica como marcar aulas e exibe um botão para iniciar o agendamento.

Os dados são armazenados em banco de dados, permitindo até quatro participantes por aula.

O controle é feito via CPF e ID da aula. O sistema valida se já há agendamento ou se a sala está cheia.

AUTORES

A aba AUTORES apresenta os criadores do projeto com seus nomes, fotos e RAs.
